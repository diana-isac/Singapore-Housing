# Grading Method

## Formula

For each listing:

`total_score = sum(weight x criterion_score) + bonuses - penalties`

Recommended score scale for each criterion:

- `0`: unacceptable
- `1`: poor
- `2`: below average
- `3`: acceptable
- `4`: strong
- `5`: ideal

## Suggested Weight Logic

- `5`: mission-critical
- `4`: very important
- `3`: important
- `2`: nice to have
- `1`: minor preference

## Recommended Thresholds

- `85%+`: strong shortlist candidate
- `70%-84%`: keep under review
- `50%-69%`: backup only
- `<50%`: reject

Adjust percentages once final criteria weights are locked.

## Bonus Examples

- exact date match
- walking distance to MRT
- all utilities included
- verified student-friendly lease

## Penalty Examples

- unknown utility costs
- unclear deposit refund terms
- source is only conditionally approved
- no live verification yet
